# 芽伴 AI 服务与管理后台

线上服务从 GitHub 拉取和更新的步骤见 [Docker 部署手册](DEPLOYMENT.md)。

## 本地运行

1. 使用 Node 22 和 pnpm。桌面根目录、`server/`、`admin/` 分别安装锁定依赖。
2. 按下表配置各端的 `.env`，每个目录均有 `.env.example`。已有数据库继续使用原加密主密钥。不要把任何凭证写入 SQL、仓库、命令参数或 `VITE_` 变量。
3. 配置 `ADMIN_PASSWORD_HASH` 后，从根目录执行 `pnpm --dir server build` 和 `pnpm --dir server db:migrate`。迁移为 `admin` 写入固定密码哈希，登录后直接进入后台，无需首次改密。固定密码见维护机上的 `docs/后台管理员凭证.md`（不随仓库分发）；新环境若没有该文档，由维护者按 [SQL 说明](sql/README.md) 设置密码并生成哈希。
4. 分别启动 `pnpm --dir server start` 和 `pnpm --dir admin dev`。默认后台入口是 `http://127.0.0.1:5180/admin`。网页使用同源 `/api/admin`，由 Vite 代理到服务端。
5. 在后台 AI 设置中保存方舟 Key 和私有 TOS 配置，再发放邀请码。执行 `pnpm tauri dev`，从领养页进入「AI 创建植物」，使用邀请码和昵称激活。方舟验证会调用一次业务对话模型，可能产生少量 Token 费用，不验证生图模型。TOS 验证会上传测试 PNG、下载并核对字节，再删除对应对象版本。验证失败保留原配置。

| 文件 | 配置 | 消费方 |
| --- | --- | --- |
| 根目录 `.env` / `.env.production` | 两种模式均使用 `VITE_AI_API_ORIGIN`，只填 Origin。开发默认 `http://127.0.0.1:3000`，生产构建以 `.env.production` 中的 `https://sproutkin.raozi666.xyz` 为默认地址 | 桌面 Vite 追加 `/api/v1/ai`，应用配置只读取对应的 Origin |
| `admin/.env` | `ADMIN_PORT` 默认 `5180`，`SERVER_PORT` 默认 `3000` | 后台 Vite 开发与预览服务器，不注入浏览器 |
| `server/.env` | `SERVER_PORT` 默认 `3000`，`ADMIN_ORIGIN` 默认 `http://127.0.0.1:5180`；另配 `DB_HOST`、`DB_PORT`、`DB_USER`、`DB_PASSWORD`、`DB_NAME` 和 `CONFIG_ENCRYPTION_KEY`（32 随机字节的十六进制字符串） | 服务端启动、数据库脚本、后台会话与凭证加密 |

服务端本地固定监听 `127.0.0.1`。改 API 端口时，同步更新桌面 Origin、后台代理端口和 [Tauri 白名单](../src-tauri/capabilities/ai-local.json) 的对应 `Origin/api/v1/ai/*`，不要扩大为域名通配。白名单不匹配时桌面 Vite 会报错；改桌面地址后需重新启动 Tauri 开发环境或重建安装包。改后台端口时，同步更新服务端 `ADMIN_ORIGIN`，并重启两端。

## 行为边界

- `admin` 管理账号、邀请和 AI 配置；其他后台账号只能查看业务内容。无角色管理或忘记密码流程。
- 普通邀请码每批可生成 1–50 个，1–30 天有效，单次兑换。默认管理员在邀请码记录中查看、复制原码和编辑可留空的备注。新增原码使用配置主密钥加密保存。早期仅有摘要的记录无法找回原码，仍可兑换。同设备重试可找回兑换结果；换机邀请单独生成，沿用身份和用量，兑换后旧设备凭证失效；撤销已兑换邀请会撤销对应身份。
- 邀请管理分别显示邀请备注和用户激活时填写的昵称。`admin` 可以停用或恢复单个身份的 AI 权限；已派发任务继续，未派发的方舟任务等待恢复。停用不撤销身份、不影响其他用户，换机也不会解除停用。已有原图仍可重传、下载和入库。升级时先迁移数据库，再统一启动新版服务端，避免旧队列进程忽略停用状态。
- 每个身份保留一份云端草稿。关闭窗口只停止客户端等待，任务进程继续执行。暂停时拒绝新方舟操作，已派发任务收尾、排队任务留待恢复；已生成图片的重传、下载和本地入库不依赖方舟开关。
- 对话可只用文字。缺少信息时可直接补充描述，参考照片为可选。档案随当轮回复保存，修改或补图时保留对话和历史方案，只有最新且已就绪的档案可用于生成。
- 草稿和参考照随草稿活动续期 30 天；云端原图与任务缓存按 30 天清理，使用中的草稿原图随活动续期。桌面已入库素材独立保存。服务进程检测过期与超时任务；无法确认方舟是否执行的请求不会自动重发。
- 每个素材保存不含凭证的稳定应用下载路径和原 TOS 对象位置，不使用公开桶或把短期签名 URL 当永久地址。换桶不会改写旧素材；在留存期内，旧桶对象和原凭证仍可用即可继续下载。不做旧桶迁移。
- `任务与用量` 默认最近七个 UTC 日，统计方舟业务调用，并按页面上的模型单价估算费用。对话费由未命中输入、缓存命中和输出分别计价，生图按实际生成张数计价。配置验证与 TOS 重传不计入。缺少计费用量的已结束调用显示为待核算，包含历史未记录缓存命中数据的对话。不设用户额度。

本地开发不包含部署、CI、发布或推送。
